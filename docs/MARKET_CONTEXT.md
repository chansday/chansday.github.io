# 시장 환경 관측

`market-context.yml`은 KST 거래일 07:30, 08:20, 16:40에 Naver 공개 JSON을 조회한다. GitHub Actions의 실제 시작은 지연될 수 있으며 파일의 `started_at`, 각 출처의 `requested_at`, `received_at`, 원천 시세의 `localTradedAt`을 사용한다. 단계명은 예정 시각을 뜻하며 해당 시각에 데이터가 있었다는 증거가 아니다.

미국 나스닥·S&P 500·필라델피아 반도체·VIX, 원/달러 고시환율, 미국 국채 2년·10년, KOSPI 현재 지수 및 KOSPI200 최신 일봉을 저장한다. 이 자료는 공식 API가 아니며 이용·재배포 권한, 지연, 수정 여부가 확인되지 않았다. 403/429 시 나머지 요청을 중단하고 실패를 기록한다. 응답 부재나 오류는 성공값으로 합성하지 않는다.

`data/market-context/YYYY-MM-DD/{phase}-{run_id}-{attempt}.json`에 각 실행을 별도로 보존한다. `manual`은 수동 실행이며 실제 시각을 기준으로 해석한다. 모든 요청이 실패해도 오류 기록을 보존하고 작업을 실패 처리한다. 국내 휴장일은 수집하지 않는다. 점수나 투자 예측은 생성하지 않는다. 미국 선물, 장전 예상체결가, 시장 전체 수급과 시장 폭은 아직 포함되지 않는다. 일봉의 당일 종가는 정산 중 바뀔 수 있다.
