# 시장 환경 관측

`market-context.yml`은 KST 거래일 07:30, 08:20, 16:40에 Naver 공개 JSON을 조회한다. GitHub Actions의 실제 시작은 지연될 수 있으며 파일의 `started_at`, 각 출처의 `requested_at`, `received_at`, 원천 시세의 `localTradedAt`을 사용한다. 단계명은 예정 시각을 뜻하며 해당 시각에 데이터가 있었다는 증거가 아니다.

네이버 공개 JSON과 미국 노동통계국(BLS) 발표 일정을 수집하고, 기존 국내 일봉 캐시에서 시장 폭을 계산한다. 네이버 자료는 공식 API가 아니며 이용·재배포 권한, 지연, 수정 여부가 확인되지 않았다. 403/429 시 나머지 요청을 중단하고 실패를 기록한다. 응답 부재나 오류는 성공값으로 합성하지 않는다.

## 데이터별 수집 이유와 한계

| 데이터 | 수집 이유 | 해석과 시점 제한 |
| --- | --- | --- |
| 나스닥 종합 | 미국 기술주 중심 시장의 야간 환경 파악 | 지수의 관측 시각·시장 상태 확인. 국내장 결과를 보장하지 않음 |
| S&P 500 | 미국 시장 전반의 움직임 파악 | 정규장 이후 새 정보는 지수 종가에 반영되지 않음 |
| 필라델피아 반도체 지수 | 국내 반도체 업종과 관련된 미국 시장 변화 관측 | 업종 간 상관관계는 변하며 인과나 예측력을 보장하지 않음 |
| VIX | 미국 옵션시장에 반영된 변동성 기대 기록 | 다음 날 하락 확률이 아님. 지연 표시 보존 |
| 미국 국채 2년·10년 | 금리와 위험 선호 환경의 변화 기록 | 원천 시세 시각과 고시 방식 확인. 경제 원인의 단정 금지 |
| 원/달러 고시환율 | 환율 변화에 따른 국내 시장 환경 관측 | 하나은행 고시회차이며 실시간 외환시장 체결가가 아님 |
| 코스피 시세 | 국내 시장 수준 및 장중·마감 결과 확인 | 원천 시세 시각과 장 상태를 보존. 장 종료 직후 정정 가능 |
| 코스피200 최신 일봉 | 대형주 지수의 일별 가격 변동 관측 | 원천은 거래 날짜만 제공하며 일봉이 확정된 시각은 알 수 없음 |
| 상승·하락·보합 종목 수와 비율 | 지수 움직임이 소수 종목에 집중되는지 관찰 | 당일 대상 캐시에서 가장 최근 과거 거래일의 두 종가를 비교. 시가 대비 장중 상승 비율이 아님 |
| 20일 이동평균 위 종목 비율 | 시장 전반의 중기 추세 폭 관찰 | 최신 종가와 최근 20개 유효 종가 평균 비교. 데이터 부족 종목 제외, 분모 별도 보존 |
| 미국 CPI·고용 발표 일정 | 예정 이벤트의 불확실성 및 발표 후 시장 반응을 연구 | BLS 일정 원문을 미국 동부시간과 함께 보존. 날짜·시각이 변경될 수 있으며 방향 예측이나 예상치가 아님 |

시장 폭은 `data/daily-history/수집일.json`의 기존 `return_history`에서 계산하며, 캐시 수집 시각이 이번 관측 시작보다 늦거나 종목 이력이 부족하면 실패 또는 제외한다. `as_of`, 캐시 수집 시각, 전체 이력 수와 각 분모를 보존한다. 특히 16:40에는 아침에 만든 캐시가 전일까지의 자료일 수 있으므로 **당일 마감 기준 시장 폭이라고 가정하지 않는다.** 원천의 우선주 포함 여부, 수정주가와 거래소 구분은 미확인이며, 살아남은 종목 편향이 있을 수 있다.

BLS 일정은 실행 시점에 공개된 일정의 사본으로, 과거에 발표된 일정과 미래 일정을 함께 저장한다. 미국 동부시간 원문과 TZID를 유지하며, 공개 시각·일정 변경 이력과 시장 예상치는 별도 확인해야 한다. 상세한 이벤트 발생 시각은 문자열만 보고 한국시간으로 추측하지 않는다.

## 미확보 항목

| 항목 | 필요한 이유 | 상태 |
| --- | --- | --- |
| 미국 지수 선물 | 미국 정규장 이후의 변화 관측 | 네이버 미국 지수 목록에서 선물 미발견, 시험한 별도 선물 경로 404. 데이터 제공 경로·만기·지연 확인 필요 |
| 국내 시장 전체 외국인·기관 수급 | 투자자별 자금 흐름 관찰 | 시험한 시장 매매동향 경로 404. 개별 종목 수급을 시장 전체로 간주하지 않음 |
| 코스피200 야간 선물 | 밤사이 국내 관련 시장 변화 관찰 | 경로 및 기준 시각 미확인 |
| VKOSPI | 국내 시장의 변동성 기대 관측 | 경로 및 지연 미확인 |
| 장전 예상체결가 | 개장 직전 매수·매도 반응 관측 | 08:20 시점에 사용할 수 없음. 별도 수집 시점과 출처 확인 필요 |

`data/market-context/YYYY-MM-DD/{phase}-{run_id}-{attempt}.json`에 각 실행을 별도로 보존한다. `manual`은 수동 실행이며 실제 시각을 기준으로 해석한다. 모든 외부 요청이 실패해도 오류 기록을 보존하고 작업을 실패 처리한다. 국내 휴장일은 수집하지 않는다. 점수나 투자 예측은 생성하지 않는다. 일봉의 당일 종가는 정산 중 바뀔 수 있다.

각 요청의 HTTP 상태, 소요 시간, 원천 관측 시각과 지연 표시, 실패 사유를 JSON과 Actions 실행 로그에 기록한다. Actions 실행 요약에는 출처별 상태와 관측 시각을 표로 보여준다. 부분 실패는 경고로 표시하며 성공한 데이터와 오류를 함께 보존한다. `localDate`만 있는 일봉은 장중 어느 시점의 값인지 알 수 없으므로 시각을 추정하지 않는다.
